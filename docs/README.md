# Документация игры

[Corwin_Amber_Game_Design_Document.docx](Corwin_Amber_Game_Design_Document.docx) описывает игровой цикл, управление, камеру, механики четырёх глав и общие игровые системы. Начинай с него, когда нужно понять назначение механики и ограничения игры.

[Corwin_4_Levels_Walkthrough.docx](Corwin_4_Levels_Walkthrough.docx) описывает препятствия, действия игрока, последовательность испытаний и состав объектов. Смотри сюда при сборке маршрута и проверке его проходимости.

Исходные DOCX сохранены без изменений. Часть решений в них различается. [Список вариантов](design-choices.md) связывает эти вопросы с issues, в которых уже представлены альтернативы для реализации. Выбор по конкретной механике нужно зафиксировать при выполнении соответствующей задачи и согласованно применять дальше.
