# Варианты игровых решений

Два исходных документа описывают разные варианты некоторых правил. Ни один из них целиком не объявлен главным. В связанных issues указаны альтернативы: при реализации выбирается один вариант, решение фиксируется в описании изменения и документации управления или уровня.

| Вопрос | Альтернативы | Задачи |
| --- | --- | --- |
| Смена Отражения | F с задержкой 0,2–0,4 с либо мгновенно по Q | [#28](https://github.com/BFGEG/Amber/issues/28) |
| Дополнительная скорость | Медленный точный ход либо бег на Shift | [#18](https://github.com/BFGEG/Amber/issues/18) |
| Выход со сцены | Автоматически при входе либо после E | [#26](https://github.com/BFGEG/Amber/issues/26) |
| Усилие в Лабиринте | Нажатия Space по импульсам и усталость либо удержание E и энергия | [#72](https://github.com/BFGEG/Amber/issues/72) |
| Сход с линии | Допуск 0,5 с либо немедленный возврат | [#69](https://github.com/BFGEG/Amber/issues/69) |
| Первая глава | Шесть зон с акведуком либо семь с башней; различаются чекпоинты | [#38](https://github.com/BFGEG/Amber/issues/38), [#40](https://github.com/BFGEG/Amber/issues/40) |
| Колвир | Шесть либо семь зон, разный запуск камнепада | [#46](https://github.com/BFGEG/Amber/issues/46), [#51](https://github.com/BFGEG/Amber/issues/51) |
| Небесный город | Разные порядок испытаний и интервалы платформ; два финальных отрезка по 30–45 с либо одна галерея на 25 с | [#53](https://github.com/BFGEG/Amber/issues/53), [#56](https://github.com/BFGEG/Amber/issues/56), [#62](https://github.com/BFGEG/Amber/issues/62), [#64](https://github.com/BFGEG/Amber/issues/64) |
| Ребма | Разные схема маршрута и число контрольных точек | [#76](https://github.com/BFGEG/Amber/issues/76) |
| Время прохождения | Около 35–55 минут либо четыре главы по 5–10 минут | [#89](https://github.com/BFGEG/Amber/issues/89) |

Общие ограничения: четыре главы от третьего лица, один управляемый Корвин, восстановление после ошибок. NPC, бои и инвентарь не входят в описанный объём. Тестовая сцена появляется первой и остаётся полигоном для следующих механик.
