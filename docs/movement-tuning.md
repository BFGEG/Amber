# Движение и прыжки — задачи #17 и #18

Базовая ветка #17 — `feat/16-test-course`, предыдущий PR —
[#113](https://github.com/BFGEG/Amber/pull/113). Задача #17 влита в `main`;
режим точного хода #18 добавлен поверх неё.

Эти параметры заменяют мгновенную скорость из задач #10–#11. Они задают
ориентиры для разрывов, подъёмов и размеров площадок при сборке следующих
уровней. Дополнительных способностей вроде двойного прыжка или рывка нет.
Удержание Shift включает медленный точный ход.

## Ориентиры

| Параметр | Значение |
| --- | --- |
| Обычная максимальная горизонтальная скорость | 7,0 м/с |
| Максимальная скорость точного хода (Shift) | 3,0 м/с |
| Разгон на земле | 40 м/с² |
| Торможение на земле | 50 м/с² |
| Разгон в воздухе | 40 м/с² |
| Гравитация | 24 м/с² |
| Начальная скорость прыжка | 8,0 м/с |
| Высота прыжка | 1,33 м |
| Время полёта на ту же высоту | 0,67 с |
| Дальность прыжка с полной скоростью на ту же высоту | 4,67 м |
| Дальность прыжка с точной скоростью на ту же высоту | около 2,0 м |
| Дальность прыжка на площадку выше на 0,75 м | около 3,88 м |
| Разгон до полной скорости | 0,175 с / 0,61 м |
| Разгон до точной скорости | 0,075 с / 0,11 м |
| Тормозной путь с полной скорости | около 0,5 м |
| Тормозной путь с точной скорости | около 0,09 м |
| Разворот с +7 до −7 м/с в воздухе | 0,35 с |
| Полуширина опоры стоп | 0,26 м |

Расчётные формулы:

- высота прыжка `h = v_jump² / (2 * g)`;
- время полёта на ту же высоту `T = 2 * v_jump / g`;
- максимальная дальность `D = v_max * T`;
- дальность точного прыжка `D_precise = v_precise * T`;
- тормозной путь `d = v_max² / (2 * braking)`.

На площадку выше на `0,75 м` персонаж приземляется за `t = (v_jump +
sqrt(v_jump² - 2 * g * 0,75)) / g` секунд; при полной скорости это около
3,88 м. Значения даны для ровной площадки и полного разгона. Для меньшей
скорости дальность меньше, поэтому перед прыжком нужен разгон.

Shift ограничивает целевую скорость на земле и в воздухе. Прыжок из точного
хода короче, поэтому перед разрывом Shift лучше отпустить.

## Правила управления

- Обычная целевая скорость — 7 м/с. Удержание Shift снижает её до 3 м/с;
  после отпускания скорость плавно возвращается к обычной.
- На земле скорость плавно приближается к целевой с ускорением 40 м/с².
- При отпускании направления на земле персонаж тормозит с 50 м/с² и
  останавливается без остаточного скольжения.
- В воздухе направление можно менять с ускорением 40 м/с²; целевая скорость
  также зависит от Shift. Без ввода горизонтальная скорость сохраняется,
  поэтому дуга прыжка предсказуема.
- После приземления остаточная скорость гасится обычным торможением.
- Диагональное движение нормализуется: скорость не выше максимальной.
- При упоре в стену скорость в заблокированную ось не сохраняется; вдоль
  свободной оси персонаж продолжает движение.
- Опора считается по стопам, а не по всему телу: чтобы стоять, вся площадь
  стоп должна помещаться на площадке. У края носки остаются на границе, а при
  следующем шаге персонаж падает. Стены и потолок по-прежнему проверяются по
  полному объёму.
- При падении достаточно частичного касания стопы: персонаж приземляется на
  край и не проваливается сквозь площадку. После такого приземления можно
  удержаться на уступе, пока стопа частично на опоре; шаг наружу снова снимает
  опору.
- При падении за границу сцены горизонтальная и вертикальная скорости,
  поворот и накопленное нажатие прыжка сбрасываются.

Space по-прежнему запускает только один прыжок при наличии опоры. Удержание
клавиши не повторяет прыжок после приземления: нужно отпустить и нажать снова.
Нажатие в воздухе не добавляет второй прыжок. Точный ход не меняет гравитацию,
высоту прыжка и проверки столкновений: он ограничивает только горизонтальную
скорость.

## Проверки

Автоматические тесты проверяют:

- разгон до максимальной скорости без превышения;
- ограничение скорости точного хода до 3 м/с и возврат к 7 м/с после Shift;
- торможение и остановку в ожидаемом интервале;
- остановку у края площадки без падения;
- остановку у края и поворот на узкой площадке в точном режиме;
- более короткий прыжок из точного хода;
- отсутствие зависания над краем: при выходе стопы за опору персонаж падает;
- приземление при частичном касании стопы и удержание на уступе;
- стояние только когда вся стопа помещается на площадке;
- разворот в воздухе и сохранение скорости без ввода;
- приземление с остаточной скоростью и остановку в пределах площадки;
- высоту и дальность прыжка с полной скоростью;
- повторный прыжок после приземления и отсутствие второго прыжка в воздухе;
- одинаковый результат обычного и точного движения при 30, 60 и 144 FPS;
- прохождение тестовой трассы после возврата на старт.

Запуск проверок:

```sh
cargo fmt --all -- --check
cargo check --locked
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
```

Ручной проход трассы с проверкой остановки у края, разворота в воздухе,
точного хода и повторного прыжка остаётся отдельной проверкой перед слиянием.
С Shift скорость должна снижаться до 3 м/с, а после отпускания возвращаться
к 7 м/с. На узком участке нужно пройти прямой отрезок, остановиться у края и
повернуть, не теряя опору. Прыжок с Shift короче; для разрывов его отпускают.
У края вся стопа должна оставаться на площадке; если шагнуть дальше, персонаж
должен упасть, а не висеть над обрывом. При прыжке на край частичное касание
стопы должно давать приземление, а не провал сквозь площадку. Сравнение
ощущений выполняется при `AMBER_MAX_FPS=30` и `AMBER_MAX_FPS=60`.

## Влияние на прежние проверки

Режим `AMBER_TIMING_DEMO=1` по-прежнему проходит 120 шагов (2 секунды), не
использует Shift и из-за разгона проходит около 13,4 м, а не 26 м. Значения
в `docs/game-time.md` и `docs/static-collisions.md` обновлены под новую
скорость.
