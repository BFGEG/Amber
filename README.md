## Сборка и запуск

Нужен стабильный Rust 1.95 или новее с Cargo. При первой сборке потребуется доступ к GitHub и реестру crates.io для загрузки зависимостей.

```sh
cargo build --locked
cargo run --locked
```

Приложение открывает статичную тестовую сцену: на широкой площадке находятся условная фигура Корвина и пять платформ разной высоты. Неподвижная камера смотрит из-за персонажа; края площадки не видны в начальном обзоре, хотя её геометрия конечна. Управление и столкновения появятся в следующих задачах. Для запуска нужны графическая сессия и доступный графический адаптер. Закрой окно, чтобы завершить приложение.

BFGE подключён как Git-зависимость на коммите `38dbcc0b9a50e9fa843bfc85b0910e2b40c125a5` с поддержкой текстур из [PR #53](https://github.com/BFGEG/BFGE/pull/53). Этот согласованный коммит следует за релизом [v0.2.0](https://github.com/BFGEG/BFGE/releases/tag/v0.2.0) и пока не входит в опубликованный релиз. Имя пакета движка — `BFGE`, в коде Amber используется имя `bfge`.

При обновлении движка выбери релиз, замени `rev` в `Cargo.toml` полным SHA его коммита, обнови `Cargo.lock` через `cargo update -p BFGE` и повтори сборку и проверки. Версия в manifest самого движка может отличаться от имени его релиза; для этой зависимости определяющей является закреплённая Git-ревизия.

Команды форматирования, линтинга и тестирования приведены в [AGENTS.md](AGENTS.md).

Текстура травы `assets/grass.png` создана с помощью генерации изображений OpenAI для тестовой сцены.
