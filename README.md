## Сборка и запуск

Нужен стабильный Rust 1.95 или новее с Cargo. При первой сборке потребуется доступ к GitHub и реестру crates.io для загрузки зависимостей.

```sh
cargo build --locked
cargo run --locked
```

Приложение открывает тестовую трассу между двумя травяными террасами.
WASD перемещает Корвина относительно камеры, мышь вращает камеру, Space
запускает прыжок, а удержание Shift включает медленный точный ход. При потере
фокуса движение и камера приостанавливаются.
Для запуска нужны графическая сессия и доступный графический адаптер.
Закрой окно, чтобы завершить приложение. [Маршрут и проверка камеры](docs/test-course.md).

Голубое небо с облаками видно во всех направлениях. Сфера с текстурой
перемещается за камерой, сохраняя ориентацию относительно мира.

[Снимок тестовой трассы](docs/test-scene.png).

BFGE подключён как Git-зависимость из ветки `main`. Конкретный коммит закреплён в `Cargo.lock`: обычная сборка с `--locked` не загружает новые изменения ветки автоматически. Имя пакета движка — `BFGE`, в коде Amber используется имя `bfge`.

Для обновления до актуального `main` выполни `cargo update -p BFGE`, сохрани изменённый `Cargo.lock` и повтори проверки. Ревизия в текущем `Cargo.lock`: `2a894b2087441694e93a19092f414bef442c4571`.
