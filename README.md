## Сборка и запуск

Нужен стабильный Rust 1.95 или новее с Cargo. При первой сборке потребуется доступ к GitHub и реестру crates.io для загрузки зависимостей.

```sh
cargo build --locked
cargo run --locked
```

Приложение открывает тестовую сцену: на широкой площадке находятся условная фигура Корвина и пять платформ разной высоты. WASD перемещает персонажа относительно камеры, мышь вращает камеру. Добавлены столкновения с боками платформ и стенами; прыжки и гравитация пока не добавлены. F3 показывает границы столкновений. При потере фокуса окна движение и камера приостанавливаются; первый кадр после возврата не догоняет время паузы. Для запуска нужны графическая сессия и доступный графический адаптер. Закрой окно, чтобы завершить приложение.

BFGE подключён как Git-зависимость из ветки `main`. Конкретный коммит закреплён в `Cargo.lock`: обычная сборка с `--locked` не загружает новые изменения ветки автоматически. Имя пакета движка — `BFGE`, в коде Amber используется имя `bfge`.

Для обновления до актуального `main` выполни `cargo update -p BFGE`, сохрани изменённый `Cargo.lock` и повтори проверки. Ревизия в текущем `Cargo.lock`: `a8d9b29d45effb22769ac0129aa1c53098f4c866`.
