## Сборка и запуск

Нужен стабильный Rust 1.95 или новее с Cargo. При первой сборке потребуется доступ к GitHub и реестру crates.io для загрузки зависимостей.

```sh
cargo build --locked
cargo run --locked
```

Приложение открывает тестовую сцену с условной фигурой Корвина и пятью платформами разной высоты. Клавиши WASD перемещают Корвина, мышь поворачивает камеру. Голубое небо с облаками окружает камеру во всех направлениях. Для запуска нужны графическая сессия и доступный графический адаптер. Закрой окно, чтобы завершить приложение.

[Снимок тестовой сцены](docs/test-scene.png).

Небо рисуется изнутри сферы, которая перемещается вместе с камерой. Радиус сферы выбран с учётом дальней плоскости BFGE. Текстура неба подготовлена под освещение тестовой сцены.

BFGE подключён как Git-зависимость на коммите `fe6f6ba1c4d1bab74b02d3c1e2deaff2be30426d`. Имя пакета движка — `BFGE`, в коде Amber используется имя `bfge`.

При обновлении движка выбери релиз, замени `rev` в `Cargo.toml` полным SHA его коммита, обнови `Cargo.lock` через `cargo update -p BFGE` и повтори сборку и проверки. Версия в manifest самого движка может отличаться от имени его релиза; для этой зависимости определяющей является закреплённая Git-ревизия.

Команды форматирования, линтинга и тестирования приведены в [AGENTS.md](AGENTS.md).

Текстура травы `assets/grass.png` создана с помощью генерации изображений OpenAI для тестовой сцены.
