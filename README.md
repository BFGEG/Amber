## Сборка и запуск

Нужен стабильный Rust 1.95 или новее с Cargo. При первой сборке потребуется доступ к GitHub и реестру crates.io для загрузки зависимостей.

```sh
cargo build --locked
cargo run --locked
```

Приложение открывает тестовую сцену: на широкой площадке находятся условная фигура Корвина и пять платформ разной высоты. WASD перемещает персонажа относительно камеры, мышь вращает камеру. Столкновения и прыжки пока не добавлены. При потере фокуса окна движение и камера приостанавливаются; первый кадр после возврата не догоняет время паузы. Для запуска нужны графическая сессия и доступный графический адаптер. Закрой окно, чтобы завершить приложение.

BFGE временно подключён на полном SHA `2b1457c3b4a0d0c168a82196bdaa79835073d62e` из [PR #58](https://github.com/BFGEG/BFGE/pull/58), предоставляющего фокус окна. Эта ревизия не является опубликованным релизом: последний исходный ориентир — [v0.2.0](https://github.com/BFGEG/BFGE/releases/tag/v0.2.0), после которого добавлены текстуры и ввод. Перед слиянием Amber нужно дождаться принятия PR движка и при необходимости заменить SHA принятым согласованным коммитом. Имя пакета движка — `BFGE`, в коде Amber используется имя `bfge`.

При обновлении движка выбери релиз, замени `rev` в `Cargo.toml` полным SHA его коммита, обнови `Cargo.lock` через `cargo update -p BFGE` и повтори сборку и проверки. Версия в manifest самого движка может отличаться от имени его релиза; для этой зависимости определяющей является закреплённая Git-ревизия.

Команды форматирования, линтинга и тестирования приведены в [AGENTS.md](AGENTS.md).

Текстура травы `assets/grass.png` создана с помощью генерации изображений OpenAI для тестовой сцены.
